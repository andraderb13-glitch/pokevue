# Reaproveitamento do projeto anterior

1. Copie imagens antigas para `public/images/`.
2. Copie sons antigos para `public/sounds/`.
3. Para usar uma imagem do dispositivo antigo, troque o CSS/markup do componente `PokedexDevice.vue` conforme o nome real do arquivo.
4. Os estilos antigos podem servir como referência, mas não devem ser colados integralmente sem revisar seletores globais, pois agora cada componente possui classes próprias.
5. O botão de som nesta primeira versão é um controle visual; a reprodução será ligada aos arquivos reais quando forem adicionados.
